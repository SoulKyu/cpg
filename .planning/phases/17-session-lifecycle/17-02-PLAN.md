Purpose: give 17-03's Manager a landed, tested vocabulary (state, results, config recipe) so it can focus purely on the concurrency-critical state machine.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP tool args (untrusted, LLM-supplied) → PipelineConfig | Numeric/duration args omitted or malformed by an LLM client become Go zero values that can crash or unbound the pipeline |
| pipeline goroutine → session stats field | OnFinal writes stats on the pipeline goroutine; Status/Stop read them on another goroutine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-17-02-01 | Denial of Service (process-crashing ticker panic) | `buildPipelineConfig` FlushInterval | mitigate | `defaultDuration(args.FlushInterval, 5s)` guarantees `> 0` reaches `PipelineConfig.FlushInterval`; `time.NewTicker` (aggregator.go:365) never receives 0. `TestBuildPipelineConfig` asserts the defaulting |
