Output: `mcp_query.go` with `registerQueryTools` + 3 handlers; the one-line wiring in `mcp.go`; and the in-memory-harness test file seeded with these three tools' scenarios.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03-01 | Tampering / Information Disclosure | get_policy namespace/workload → filepath.Join | mitigate | Reuse evidence.ValidatePolicyRef before every path construction (rejects empty, "."/"..", path separators) — the exact write-side guard applied symmetrically on the read side (RESEARCH Security Domain V12) |
| T-18-03-02 | Spoofing | unknown/purged/replaced session_id | mitigate | resolveSession delegates to mgr.Status verbatim — SESS-06 "not found or expired", never a generic failure; a retained STOPPED session stays queryable (D-02) |
